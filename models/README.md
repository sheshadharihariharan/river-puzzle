# Models

Put your Tripo .glb files here, named as in ART_BREAKDOWN.md (hero.glb, cottage.glb, rock-a.glb ...).
The game picks each one up automatically. Anything missing uses a stand-in built from simple shapes.
Hero animations can be inside hero.glb or separate files: hero-idle.glb, hero-walk.glb, hero-hop.glb, hero-fall.glb, hero-cheer.glb.
